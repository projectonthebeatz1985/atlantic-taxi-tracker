ATLANTIC TAXI TRACKER V41 — DRIVER HUB SCROLL OVERHAUL

Based on V40.

This update changes only how the embedded Driver Hub reports its full content height:
- The Driver Hub now reports its natural document height to the main tracker.
- The main tracker expands the iframe to that exact content height.
- The nested iframe scrollbar is disabled, so the main page/tab scroll handles the whole Driver Hub like the other tabs.
- Height updates are bounded and only applied when the actual content height changes, avoiding the runaway resize loop from earlier versions.
- The map and content below it should remain reachable without a second scroll area.

Preserves V28 styling, GPS sharing, map popup fixes, Supabase settings, and existing data/features.

INSTALL:
1. Extract this ZIP.
2. Replace all files and folders in the root of the same GitHub Pages repository.
3. Keep atlantic_companion beside the main index.html.
4. Commit and wait for GitHub Pages deployment.
5. On phone, fully close the installed app, reopen it, and refresh the live page once to pick up the new service-worker cache.

No Supabase SQL changes required.
