ATLANTIC TAXI TRACKER V45 — REMOVE ESTIMATED MILES & FARE

Based on V44 Separate Customer App.

Changes in the staff/Driver Hub dispatch booking form:
- Removed Estimated miles and Estimated fare fields.
- Removed the estimate formula/explanation.
- New bookings save zero in the legacy estimated_miles and estimated_fare database columns for compatibility; no estimate is shown to drivers or dispatch.
- Driver assigned-ride cards no longer show an estimate.
- Dispatch booking list no longer shows an estimate.
- Editing cancelled rides now edits pickup and destination only.
- Drivers still enter the actual final meter fare when pressing Complete trip. The final fare is saved to final_fare with the completion timestamp.

Important:
- Staff and customer apps remain separate.
- Customer app, map, ride codes, GPS sharing, Supabase configuration, and V41 scrolling behavior are preserved.
- No Supabase schema or SQL changes required.

Install:
1. Extract this ZIP.
2. Upload all files and folders to the root of the existing GitHub repository, preserving customer/ and atlantic_companion/.
3. Commit changes and wait for GitHub Pages deployment.
4. Staff app remains at the repository root URL; customer app remains under /customer/.
5. Refresh the staff app. On phones, fully close/reopen if the old cached version remains.
