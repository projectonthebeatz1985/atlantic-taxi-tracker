ATLANTIC TAXI TRACKER V39 — STABLE SINGLE SCROLL

Based on V38.
Fixes the runaway/infinite Driver Hub scrolling by removing the self-triggering MutationObserver/ResizeObserver height loop. The iframe is measured from its embedded main content at load and a few times after map/dashboard initialization, then on window resize only. This avoids continually increasing the iframe height.

Preserves V28 styling, small top gap, GPS sharing, Supabase settings, map popup styling, and Driver Hub.

Install all files/folders into the root of the same GitHub Pages repository, keeping atlantic_companion beside index.html. Commit, wait for deploy, then hard refresh (Ctrl+F5); close/reopen installed PWA if needed. No Supabase changes required.
