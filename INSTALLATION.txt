ATLANTIC TAXI TRACKER V43 — CUSTOMER MAP FIX

Based on V42.
Fixes:
- Removed a customer-mode CSS rule that kept the ride result section hidden even after a valid ride code was entered.
- Shows the ride result section before initializing MapLibre, so the map gets real dimensions.
- Resizes the map after the customer tracking screen is revealed.
- Keeps customer-only experience, private ride code, driver location, status, pickup/destination, sound alerts, and no estimated fare display.
- Staff/admin/driver app remains unchanged.

Install:
1. Extract this ZIP.
2. Replace all files/folders in the root of your existing GitHub repository.
3. Ensure the customer folder and atlantic_companion folder are both uploaded.
4. Commit and wait for GitHub Pages deployment.
5. Customer URL: https://projectonthebeatz1985.github.io/atlantic-taxi-tracker/customer/
6. On phones, fully close and reopen the installed customer app, or refresh the customer URL.

No Supabase changes required.
